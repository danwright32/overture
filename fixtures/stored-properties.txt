# Every stored property of every model in AppSchema, as "Entity.property" (#3558).
#
# Each line is a column in Dan's live SwiftData store. StoredPropertyRatchetTests derives the stored
# properties from the same Schema the app opens its store with and holds them against this file.
#
# This is a RATCHET in one direction.
#
# It may GROW freely. Adding a column is the safe direction (SwiftData's lightweight migration handles
# it), and a new property must be added here so that its own later removal is caught too.
#
# It may SHRINK only deliberately. Removing a line means dropping a column from the live store, which is
# this app's first SUBTRACTIVE migration: there is no MigrationPlan or VersionedSchema, and the launch
# backup is the only net. That removal gets its own change, with a rehearsal against a clone of the live
# store (see InquiryMigrationDryRunTests), and the change that deletes the lines here is where that
# rehearsal is stated. A property read and written by nothing stays on the model as RETAINED STORAGE
# (see Recipient.overrideBody) until then.
#
# Why this exists: on 2026-09-05 #3549 deleted Recipient.overrideBody, a persisted property, and pushed it
# with a full green suite. It was caught only because somebody happened to read a comment.
